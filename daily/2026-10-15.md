### Python练习
1.字典这个类的一个方法，看下列展示。
```python
tmp = dict.fromkeys(['a', 'b'], 4)
print(tmp)
```
输出为：
```python
{'a'=4,'b'=4}  #fromkeys这个方法会先读取keys，再讲keys与后面的值一一对应，用于创建新的字典。
```
2.解释型的语言特点就是非独立性以及效率低，非独立是因为需要解释器进行逐行解释运行。Python以及JavaScript都是这样的。
3.str.format() :一种针对字符串对象的方法，
```python
'我叫{}，今年{}岁'.format('小明', 20)
# → '我叫小明，今年20岁'会按顺序把值填进去，{}是占位符。
```
4.int()的强制转换
```python
str=A
print(int(A,16))
```
这个时候会输出10，当然要记得第一个参数应该是字符串。

5.字符串的多种类方法
```python
str.title() #每个单词的首字母大写
str.swapcase() #字符串的大小写互换
str.capitalize() #整条字串只有第一个首字母大写，其余均小写
str.strip() #去掉字符串左右的空白符
str.lstrip() #去掉字符串左边的空白符
str.rstrip() #去掉字符串右边的空白符
```
