### MNIST 代码详解
```python
from torch import nn
# 所有 PyTorch 模型都要继承 nn.Module，这是 PyTorch 的“模型积木基座”。继承后，自动获得参数管理、GPU 迁移、训练/推理模式切换等能力。
一个标准模板包含两部分：__init__（定义有哪些层）和 forward（规定数据怎么流过这些层）。__init__ 是“装修图纸”，forward 是“参观路线”。
PyTorch 的 nn 模块包含了构建神经网络所需的常用组件，例如：
- nn.Conv2d：二维卷积层
- nn.ReLU：激活函数
- nn.MaxPool2d：最大池化层
- nn.Linear：全连接层
- nn.Sequential：把多个层按顺序组合起来
- nn.Module：所有神经网络模型的基类
#class MnistCNN(nn.Module) 是 Python 的类继承（inheritance），读作： “MnistCNN 是一种 nn.Module” ​。这代表MnistCNN 这个类继承了 nn.Module 的全部能力。在 PyTorch 中，自己编写的神经网络通常都要继承 nn.Module。继承以后，PyTorch 才能自动完成这些工作：
- 收集模型中需要训练的参数
- 将模型移动到 GPU
- 保存和加载模型
- 切换训练和推理模式
- 计算梯度并更新参数

    def __init__(self):         #开始定义layers（层）
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),   # 保持28×28尺寸。
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),                  # 下采样为14×14。
            nn.Conv2d(16, 32, kernel_size=3, padding=1),  # 保持14×14尺寸。
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),                  # 下采样为7×7。
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(32 * 7 * 7, 10),  # 输出0—9十个类别的分数。
        )

    def forward(self, inputs):
        features = self.features(inputs)
        return self.classifier(features)

```
