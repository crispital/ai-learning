### MNIST 代码详解
```python
from torch import nn
# 所有 PyTorch 模型都要继承 nn.Module，这是 PyTorch 的“模型积木基座”。继承后，自动获得参数管理、GPU 迁移、训练/推理模式切换等能力。
一个标准模板包含两部分：__init__（定义有哪些层）和 forward（规定数据怎么流过这些层）。__init__ 是“装修图纸”，forward 是“参观路线”。

class MnistCNN(nn.Module):
#class MnistCNN(nn.Module) 是 Python 的类继承（inheritance），读作： “MnistCNN 是一种 nn.Module” ​。这代表MnistCNN 这个类继承了 nn.Module 的全部能力——nn.Module 里定义的属性和方法，MnistCNN 自动全都有。比如你能在 model 上直接调用 model.parameters()、model.to('cuda')、model.train()、model.eval()——这些方法你在代码里从没写过，它们都是从 nn.Module 那里"白拿"的。这样的话每个 MnistCNN() 创建出来的实例（对象），自然也就具备这些能力——这是继承的结果，不是继承的定义。
    """用于MNIST分类的简单卷积神经网络。

    输入形状为[N, 1, 28, 28]，输出形状为[N, 10]。输出是十个类别的
    原始分数（logits），训练时直接交给CrossEntropyLoss，不先做softmax。
    """

    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),   # 保持28×28尺寸。
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),                  # 下采样为14×14。
            nn.Conv2d(16, 32, kernel_size=3, padding=1),  # 保持14×14尺寸。
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),                  # 下采样为7×7。
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(32 * 7 * 7, 10),  # 输出0—9十个类别的分数。
        )

    def forward(self, inputs):
        features = self.features(inputs)
        return self.classifier(features)

```
