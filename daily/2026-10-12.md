### MNIST 代码详解
```python
from torch import nn
# 所有 PyTorch 模型都要继承 nn.Module，这是 PyTorch 的“模型积木基座”。继承后，自动获得参数管理、GPU 迁移、训练/推理模式切换等能力。一个标准模板包含两部分：__init__（定义有哪些层）和 forward（规定数据怎么流过这些层）。__init__ 是“装修图纸”，forward 是“参观路线”。PyTorch 的 nn 模块包含了构建神经网络所需的常用组件，例如：
- nn.Conv2d：二维卷积层
- nn.ReLU：激活函数
- nn.MaxPool2d：最大池化层
- nn.Linear：全连接层
- nn.Sequential：把多个层按顺序组合起来
- nn.Module：所有神经网络模型的基类
class MnistCNN(nn.Module) #是 Python 的类继承（inheritance），读作： “MnistCNN 是一种 nn.Module” ​。这代表MnistCNN 这个类继承了 nn.Module 的全部能力。在 PyTorch 中，自己编写的神经网络通常都要继承 nn.Module。继承以后，PyTorch 才能自动完成这些工作：
- 收集模型中需要训练的参数
- 将模型移动到 GPU
- 保存和加载模型
- 切换训练和推理模式
- 计算梯度并更新参数

    def __init__(self):         #类的初始化方法，当我们创建一个model时候，python就会开始自动调用这个方法。
        super().__init__()      #初始化父类nn.moudule,如果省略PyTorch 可能无法正确登记卷积层、全连接层及其中的参数。简单点来说，新建的model属于nn.Module的子类，只有写了这一行，才算正式调用了父类的初始化流程。
```
```python
        self.features = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),   # Sequential会确保后面创建的各层顺序连接。
#输出尺寸 = (输入尺寸 + 2×padding - kernel_size) / stride + 1
            nn.ReLU(),                                    #ReLU(x)=max(0,x);引入非线性，增强学习能力
            nn.MaxPool2d(kernel_size=2),                  # 池化，压缩特征图，减少计算，保留明显特征
            nn.Conv2d(16, 32, kernel_size=3, padding=1),  # 保持14×14尺寸。
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),                  # 第二次池化，输出32*7*7
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),#Flatten（展平） 默认保留第一个批次维度 N，只展平后面的维度。输出N*1568
            nn.Linear(32 * 7 * 7, 10),  # 全连接层，它将每张图片的 1568 个特征映射为 10 个分数。
        )

    def forward(self, inputs):
        features = self.features(inputs)
        return self.classifier(features)

```
