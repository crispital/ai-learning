### PowerShell 命令
  今天开始区分一下PowerShell的命令，不求短时间内能写，只要求自己能读懂。
今天主要分清-m和-c的含义，例句:
```powershell
.\.venv\Scripts\python.exe -m pip install torch onnx onnxscript
# 安装pytorch;
#onnx：处理、检查 ONNX 模型的工具包;
#onnxscript：PyTorch 导出 ONNX 模型时使用的辅助依赖。
#这里-m主要是指代让python解释器以模块运行(module)pip，前面的.\主要指代在当前文件夹下运行python解释器
#(注：在创建环境的那一步就会找到电脑里的python解释器位置，然后为新建的环境里准备一个python解释器，新的环境里的 pyvenv.cfg 文件会记录真实的python解释器位置。)，
#python -m venv .venv就是利用venv模块去创建环境,结构如下：
.venv/
├── Scripts/
│   ├── python.exe       ← 环境中的 Python 启动程序
│   └── pip.exe
├── Lib/
│   └── site-packages/   ← 这个环境安装的第三方包
└── pyvenv.cfg           ← 记录基础 Python 的位置等信息
```
而-c就是为了让 Python 直接执行后面引号里的代码。不需要先保存为.py 文件。如:
```powershell
.\.venv\Scripts\python.exe -c "import torch; print('PyTorch:', torch.__version__); print('CUDA:', torch.version.cuda); print('GPU可用:', torch.cuda.is_available()); print('GPU:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else '不可用')"
#这样会去直接执行" "中的代码，注意每句代码之间用；分开，这样可以写在一行。
```

## 代码或实验
准备一个基础的机器学习小项目，用于上手。见project分支。主要输入一张 28×28 的灰度手写数字图片，输出 0～9 中的一个数字。
MNIST是一个经典的手写数字图片数据集，常用于入门机器学习。
它包含：
- 60,000 张训练图片：用来训练模型。
- 10,000 张测试图片：用来检查模型识别新图片的能力。
- 每张图片都是 28×28 像素的灰度图，内容是手写的 0～9。
例如，一张图片画着手写数字“7”，它的标签就是 7。训练时，模型根据预测和标签之间的差距调整参数，逐渐学会识别数字。灰度图就是只用黑、白和不同深浅的灰色表示的图片，没有红、绿、蓝等颜色。
每个像素用一个数表示亮度。常见的 8 位灰度图中：
- 0：黑色
- 255：白色
- 中间的数值：不同深浅的灰色，数值越大越亮
例如，128 大约是中等亮度的灰色。
MNIST 图片是 28×28 的灰度图，因此每张图有 784 个亮度值。通常是黑色背景、明亮的数字笔画。
彩色图片一般用 R、G、B 三个通道表示颜色；灰度图只需要一个通道。所以我们项目中的输入形状：
[batch, 1, 28, 28]     分别表示：图片数量、1 个灰度通道、高 28、宽 28。
