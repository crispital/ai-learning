### PyTorch学习
  今天开始正式接触PyTorch的一些代码使用，今天希望借助借助一些基本知识，先创建一个自己的小型神经网络。直接上代码(这些代码都是配置好环境后直接可用的，配合实际操作理解起来很快)：
```python
import torch
a = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
print("从列表创建:\n", a)
print("形状 shape:", a.shape)        # 每一维的大小
print("数据类型 dtype:", a.dtype)    # 默认 float32
print("所在设备 device:", a.device)  # 默认在 CPU 上
```
简单创建了一个张量，然后展示了张量常见的一些属性，如shape，数据类型，以及所在设备（当然可以切换到GPU上）
然后来了解一些基本的tensor函数
```python
# ---- 常用的"工厂函数" ----
zeros = torch.zeros(2, 3)            # 全 0
ones = torch.ones(2, 3)              # 全 1
rand = torch.rand(2, 3)              # [0,1) 均匀分布
normal = torch.randn(3, 2, 2)           # 标准正态分布(最常用于初始化权重)
arange = torch.arange(0, 10, 2)      # 类似 range()
print("\nrandn(3,2,2):\n", normal)
```
使用张量函数创建张量的参数量直接决定了张量的维度，一个参数可以理解为创建了一个向量，两个为矩阵，三个等继续往高维空间去推导，比如torch.rand(2, 3)就是创建了一个2行3列的矩阵，当然这是不准确的理解，但是有助于理解张量的维度这一概念。
